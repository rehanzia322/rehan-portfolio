# Rehan Zia | Portfolio

Personal portfolio of Rehan Zia, Graphic Designer and Video Editor from Bahawalpur, Pakistan.

Built with plain HTML, CSS and JavaScript. No build step.

## Edit the content

All text, links and skills are in `portfolio.config.js`. Change the text between the quotes, save, and refresh `index.html`.
